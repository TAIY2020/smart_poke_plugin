# 智能戳一戳插件 (SmartPoke Plugin)

👆 **一个让麦麦在 QQ 戳一戳里尽量像真人一样反应的拟人化交互插件。**

这个插件让麦麦在被戳时按概率随机选择回戳、让 LLM 即兴回一句、发表情包、甩句吐槽或干脆装作没看见。当群里其他人互戳时麦麦还会忍不住"跟风"凑一脚；群里有人说话时也可能被勾起来主动戳一下熟人，制造点群聊乐子。

> 本版本基于 **MaiBot SDK v2** 开发，使用 `PluginConfigBase` 强类型配置模型，支持配置热重载和 Web UI 配置。**推荐通过 Web UI 修改配置**，所见即所得，不用记字段名。

## ✨ 功能特性

- **被戳反应**: 被戳时按概率随机回戳、发文字、发表情、调用 LLM 即兴回复或保持沉默，让麦麦的反应不再机械。
- **LLM 智能回复**: 被戳时可按权重概率交给 LLM 即兴生成一句符合人设的回复，**不走主程序回复链路**，自带「思考延迟」与失败回退；人设默认跟随麦麦的全局设定。
- **跟风戳**: 检测到群里别人互戳时，麦麦也会按概率跟着戳一下，目标可选「跟着欺负被戳者」「替被戳者还击」或「随机选一个」。
- **主动戳**: 群里有人说话时，麦麦会以低概率被"勾起戳意"主动戳一下熟人，制造群聊话题。
- **暴戳检测**: 被同一个人短时间内反复戳后切换到"被烦了"状态，语气会更冲。
- **思考延迟**: 反应前有随机延迟，避免机器人秒回的违和感。
- **多层冷却**: 戳麦麦冷却、跟风冷却、主动戳冷却各自独立，互不干扰；还有每分钟反应上限与每日主动戳上限做总量控制。
- **黑白名单**: 黑名单内的人戳麦麦会被静默忽略；主动戳额外支持群级白名单/黑名单。
- **场景开关**: 群聊响应、私聊响应、跟风戳、主动戳都可以单独开关。
- **配置热重载**: 通过 Web UI 修改配置后无需重启，插件会自动应用新配置。
- **写入上下文（实验性）**: 可选把麦麦自己的戳行为与文字/表情/LLM 回复的具体内容写入聊天上下文，让它在后续聊天里"记得"刚刚戳过谁、回过什么。

## 🚀 快速开始

### 1. 安装

- 自动安装：通过 Web UI 在插件市场下载安装（**推荐**）
- 手动安装：下载 `smart_poke_plugin` 文件夹放入麦麦主程序的 `plugins` 目录下，然后重启主程序即可完成插件的注册和加载。

### 2. 环境要求

- **MaiBot 主程序**: v1.0.0+
- **MaiBot SDK**: v2.0.0+
- **MaiBot-Napcat-Adapter**: 版本 ≥ 1.2.0（自该版本起，适配器在源头按聊天名单过滤戳一戳等 notice 事件；本插件已据此移除自带的「聊天范围」兜底名单，请确保适配器不低于此版本）

### 3. 配置

首次启动麦麦后，插件会在其目录下自动生成 `config.toml` 文件，开箱即用。**推荐通过 Web UI 在线修改配置**，修改后会自动热重载生效；下面的字段名仅供进阶用户直接编辑配置文件时参考。

**⚠️ 重要安全提示**（Web UI 同名项）:

- **「黑名单 QQ」**: 黑名单 QQ 号字符串列表。被列入的人戳麦麦会被静默忽略；跟风戳和主动戳也都不会戳到他们。例如：`["12345", "67890"]`。
- **「忽略自戳」**: 是否忽略麦麦戳自己。**默认开启，强烈建议保留**，避免麦麦因为各种原因戳到自己时陷入自戳循环。
- **「活跃时段开始（小时）」 / 「活跃时段结束（小时）」**: 主动戳的活跃时段（24 小时制）。**默认 9 ~ 24**，即上午 9 点到当晚 24 点活跃，9 点之前（凌晨 0~8 点）不会主动戳人。如果想让麦麦凌晨也能蹦出来戳人，把开始时间调小、结束时间调大即可；两个值相等表示全天活跃。
- **「群白名单」 / 「群黑名单」**: 主动戳的群级名单。白名单非空时只在白名单的群里允许主动戳；黑名单优先生效，即使在白名单里也不会戳。

## 📖 使用指南

本插件没有任何命令——所有行为都是对戳一戳事件的被动响应。安装并配置后，把 QQ 客户端打开戳麦麦一下就能看到效果。

### 戳麦麦本人

任何人戳麦麦时，麦麦会按概率随机做出以下反应之一：

- **回戳**: 直接戳回去（暴戳状态下可能连戳几下）。
- **文字调侃**: 随机说一句话，普通状态用「普通回复池」，暴戳状态用「暴戳回复池」，语气更冲。
- **发表情包**: 按配置的关键词随机找一张匹配的表情发出去。
- **LLM 生成回复**: 交给 LLM 即兴生成一句符合人设的回复，不走主程序回复链路；失败会自动回退到回戳或回复池。
- **保持沉默**: 装作没看见。偶尔还会嘀咕一句「沉默回复池」里的内容。

冷却期内被戳会被静默忽略；同一个群里被太多人轮番戳时也会自动降频（按会话独立，不会波及其他群），避免麦麦像永动机一样回个不停。

### 跟风戳（别人互戳时）

当群里 A 戳了 B（且 B 不是麦麦），麦麦会按概率"跟风"也戳一下，目标由「目标策略」决定：

- **「戳被戳者」**（默认）: 跟着欺负 B。
- **「戳发起者」**: 替被戳者还击 A。
- **「随机选一个」**: 在 A、B 中随机选一个。

跟风戳仅在群聊生效；私聊场景天然不存在第三方目标。

### 主动戳（群里有人说话时）

主动戳是把"群里有新消息"当成"麦麦醒了一瞬间"，按概率被勾起戳意去戳一下最近说话的熟人。仅群聊触发，私聊不会。

为了让麦麦不显得机械或骚扰，主动戳叠加了好几层"克制"：

- **活跃时段**: 默认上午 9 点之前（凌晨 0~8 点）完全不戳。
- **群活跃度**: 死群里偶尔有一条消息不会触发，要群里最近确实在聊天才出手。
- **冷却与上限**: 每个群有「同群冷却」、全局有「全局冷却」、每天还有「每日上限」。
- **避开刚戳过麦麦的人**: 防止报复性骚扰，让对方觉得"被麦麦针对"。
- **群级名单**: 可以指定哪些群允许主动戳、哪些群永不戳。

### 暴戳模式

被同一个人短时间内反复戳到一定次数后，麦麦会进入"被烦了"状态：

- 反应风格偏向文字，语气更冲，从「暴戳回复池」里抽话。
- 如果抽中回戳，会连戳几下（次数取决于「回戳次数上限」），把"我不耐烦了"演到位。
- 文字反应兜底链只在「暴戳回复池」与「普通回复池」之间回退，**不会落到「沉默回复池」**——暴戳态下蹦个 `...` 反差太大；前两档都为空时会自动改走回戳，避免失声。
- 跟风戳和主动戳不受影响。

### 把戳与回复写入记忆（实验性）

默认关闭。开启「把自己的戳与回复写入上下文」后，麦麦的每次戳一戳互动都会追加到对应聊天的上下文里，让它在后续聊天里能"记得"自己刚刚经历了什么：

- **戳一戳动作**: 别人戳麦麦、以及麦麦回戳 / 跟风 / 主动戳 → 用 QQ 原生提示风格写入，如"东雪莲戳了戳我""我戳了戳东雪莲"；若对方设置了自定义戳一戳文案（如"拍了拍""捏了捏"），会按**实际动作**写入（"东雪莲拍了拍我"），LLM 回复也会据此应答。
- **回复内容**: 被戳后发出的文字 / 表情 / LLM 回复（含沉默档的嘀咕）→ 按正常聊天记录格式写入（带说话人前缀、等同麦麦自己的发言）。

> ⚠️ 实验性功能，会在上下文里多出戳一戳互动的痕迹；不需要可保持关闭（默认就是关闭）。受底层接口限制，戳一戳动作是以一行文本融入（句中的"我"指麦麦），不带真实消息那样独立的说话人字段。

### 配置项说明

下表第一列为 Web UI 中显示的配置项名称（括号内为对应的 TOML 字段名，进阶用户直接改 `config.toml` 时使用）。

#### 反应行为

| 配置项（Web UI / TOML） | 默认值 | 说明 |
| ------ | ------ | ---- |
| 反应概率（`react_probability`） | `0.85` | 被戳时做出反应的概率，越大越爱搭理 |
| 回戳权重（`back_poke_weight`） | `0.6` | 反应里"回戳"的权重 |
| LLM 回复权重（`llm_weight`） | `0.3` | 反应里"调用 LLM 即兴生成"的权重；`0` 关闭该档 |
| 表情权重（`emoji_weight`） | `0.15` | 反应里"表情包"的权重 |
| 文字权重（`text_weight`） | `0.1` | 反应里"文字"的权重（四档权重不要求加起来等于 1） |
| 沉默时发言概率（`silent_chat_probability`） | `0.1` | 装作没看见时偶尔嘀咕一句的概率 |
| 沉默时吞事件（`swallow_when_silent`） | `true` | 沉默时是否完全吞掉事件；关闭后会把事件放行给主程序自带的回应 |
| 最小延迟（秒）（`min_delay_seconds`） | `1.0` | 反应前的随机思考延迟下限 |
| 最大延迟（秒）（`max_delay_seconds`） | `2.5` | 反应前的随机思考延迟上限 |
| 冷却时长（秒）（`cooldown_seconds`） | `8` | 同一个人戳麦麦的冷却时长 |
| 每分钟反应上限（`max_reactions_per_minute`） | `6` | 同一会话（群/私聊）1 分钟内反应次数上限，按会话独立计数、不同群互不影响；0 表示不限制 |
| 回戳次数上限（`back_poke_max_times`） | `3` | 回戳连续次数上限，默认 3 让暴戳态连戳几下；调到 1 退化为单次，调到 4~5 更狠 |
| 暴戳阈值（`spam_threshold`） | `5` | 进入暴戳状态需要的连续戳次数 |
| 暴戳窗口（秒）（`spam_window_seconds`） | `45` | 暴戳判定的时间窗口 |
| 群聊响应（`react_in_group`） | `true` | 是否在群聊中响应戳一戳 |
| 私聊响应（`react_in_private`） | `true` | 是否在私聊中响应戳一戳 |

#### LLM 反应档

> 当「LLM 回复权重」> 0 时，被戳有概率交给 LLM 即兴生成回复。该档直接调用麦麦的模型生成、**不走主程序回复链路**，生成时把「思考延迟」与请求并行以抵消等待；生成失败会自动回退到文字回复池 / 回戳。

| 配置项（Web UI / TOML） | 默认值 | 说明 |
| ------ | ------ | ---- |
| LLM 模型槽位（`llm_model`） | `planner` | 使用哪个模型任务槽位（`utils` / `replyer` / `planner`），对应麦麦 `model_config.toml` 里的任务名；建议选已配置了快模型的槽位（`utils`/`planner` 一般是快模型，`replyer` 最贴人设但可能较慢） |
| LLM 最大 token（`llm_max_tokens`） | `256` | 单次生成的最大 token，戳一戳回复一两句即可；`0` 表示改用模型配置默认值 |
| LLM 温度（`llm_temperature`） | `1.0` | 采样温度，越高回复越随机有梗 |
| LLM 人设（`llm_persona`） | 留空 | 生成时注入的人设 / 语气；**留空自动跟随麦麦的全局人设**（`personality.personality`），填写则覆盖，可给戳一戳单独定制语气 |
| LLM 额外回复风格（`llm_response_style`） | 留空 | 在人设之上额外叠加的回复腔调；**默认留空——不再硬塞「讽刺」等固定风格，语气完全由人设决定**（修复硬编码风格冲淡人设的问题）；需要单独定调时再填，如「语气温和一点，像朋友随口吐槽」 |
| LLM 上下文消息数（`llm_context_messages`） | `0` | 生成回复前额外拉取最近多少条聊天记录作为氛围参考注入提示词。`0` 表示不拉取（**默认、最快**，戳一戳作为独立轻量交互）；填 `5~10` 可让被戳回复接住群里 / 对话正在聊的话题，代价是生成前多一次拉取延迟。仅在「LLM 回复权重」> 0 时生效 |

## 📝 注意事项

- **默认配置已经调好**: 大多数场景下默认值足够用，不建议一上来就大改概率或冷却。觉得麦麦太活跃就在 Web UI 里把「反应概率」「跟风戳概率」「出手概率」往小调；反之亦然。
- **主动戳的"克制感"**: 默认每天最多成功 3 次、同群冷却 10 分钟、凌晨不戳人——这些组合起来才是它"像真人"的关键。如果觉得麦麦不太主动，可以试试调大「出手概率」或缩短「同群冷却（秒）」，但建议幅度小一点慢慢试。
- **配置热重载**: 通过 Web UI 修改配置后会自动生效，不需要重启麦麦。

Enjoy! 🎉
